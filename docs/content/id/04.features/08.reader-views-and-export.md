Selain output cetak statis, Printedjs menyediakan mode presentasi dokumen interaktif, drawer navigasi, serta ekspor PDF langsung dari sisi client.

## 1. 3D Flipbook Interaktif

Package `@printedjs/plugin-page-flip` menyediakan mode presentasi buku 3D dengan akselerasi hardware. Mode ini mendukung animasi balik halaman dengan dragging sudut mouse, navigasi keyboard, dan kelengkungan kertas realistis langsung di browser:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";
import { pageFlipPlugin } from "@printedjs/plugin-page-flip";

const renderer = createRenderer({
	target: document.querySelector("#reader")!,
	plugins: [
		...standardPreset(),
		pageFlipPlugin({
			width: 300,
			height: 420,
			showCover: true,
		}),
	],
});
```

## 2. Tampilan Dua Halaman (`"spread"`)

Tampilan dua halaman berdampingan (facing spreads) menyajikan halaman layaknya buku fisik yang terbuka, lengkap dengan bayangan lipatan jilid:

```typescript
import { pageViewsPlugin } from "@printedjs/plugins";

// Pada konfigurasi renderer:
pageViewsPlugin({ defaultMode: "spread" });
```

## 3. Drawer Navigasi Bookmark TOC

Untuk dokumen panjang, Printedjs menyediakan drawer navigasi heading hierarkis:

```typescript
import { createBookmarksDrawer } from "@printedjs/plugins";

const drawer = createBookmarksDrawer({
	target: document.body,
	container: document.querySelector("#reader-viewport")!,
	title: "Navigasi Dokumen",
	collapsible: true,
});
```

---

## 4. Ekspor PDF & Cetak Langsung di Browser

Picu dialog cetak browser secara terprogram tanpa menampilkan elemen layar browser:

```typescript
import { printDocument } from "@printedjs/browser";

// Jalankan dialog cetak dengan judul bersih
await printDocument({
	target: window,
	pageTitle: "Laporan Kebijakan Perusahaan",
	cleanChrome: true, // Menyembunyikan scrollbar dan overlay layar
});
```
