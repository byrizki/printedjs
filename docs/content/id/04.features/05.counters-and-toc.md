Printedjs mendukung penuh counter halaman CSS Paged Media, penomoran Romawi atau alfabet, reset nomor per bab, serta pembuatan Daftar Isi dinamis dengan dot leaders.

## 1. Counter Halaman & Format Penomoran

CSS Paged Media menyediakan dua counter bawaan:

- `counter(page)`: Nomor halaman saat ini.
- `counter(pages)`: Jumlah total halaman dokumen.

```css
@page {
	@bottom-right {
		content: "Halaman " counter(page) " dari " counter(pages);
		font-size: 8.5pt;
		color: #64748b;
	}
}

/* Format angka Romawi kecil (i, ii, iii...) untuk halaman pengantar */
@page frontmatter {
	@bottom-right {
		content: "Halaman " counter(page, lower-roman);
	}
}
```

## 2. Reset Counter Bab (`counter-reset`)

Mulai ulang penomoran halaman dari 1 saat memasuki isi utama dokumen:

```css
.main-content {
	break-before: page;
	counter-reset: page 1;
}
```

---

## 3. Daftar Isi Dinamis (`target-counter`)

Printedjs mendukung fungsi W3C `target-counter()`. Engine ini otomatis memeriksa ID tujuan dan mengisi nomor halaman fisik ke dalam daftar isi:

```html
<nav class="toc-container">
	<div class="toc-title">Daftar Isi</div>
	<ul class="toc-list">
		<li class="toc-item">
			<a href="#sec-executive">
				<span class="toc-label">1. Ringkasan Eksekutif</span>
				<span class="toc-dots"></span>
				<span class="toc-target"></span>
			</a>
		</li>
		<li class="toc-item">
			<a href="#sec-architecture">
				<span class="toc-label">2. Prinsip Arsitektur</span>
				<span class="toc-dots"></span>
				<span class="toc-target"></span>
			</a>
		</li>
	</ul>
</nav>
```

```css
.toc-dots {
	flex-grow: 1;
	border-bottom: 1px dotted #94a3b8;
	margin: 0 6px;
}

.toc-item a .toc-target::after {
	content: target-counter(attr(href), page);
	font-weight: 700;
	color: #0284c7;
}
```
