Rendering tabel data berukuran besar yang membentang ke beberapa halaman cetak adalah salah satu tantangan tersulit pada web layout. Printedjs menyediakan pemisahan tabel otomatis dengan header berulang, sel kelanjutan `rowspan`, dan sinkronisasi lebar kolom antar halaman.

## 1. Perulangan Header Tabel (`<thead>`)

Saat elemen `<table>` terpotong oleh batas halaman, Printedjs otomatis menyalin dan menempatkan ulang `<thead>` di puncak segmen halaman berikutnya ketika perulangan diaktifkan via `class="repeat-header"` atau atribut `data-repeat="true"`:

```html
<table class="repeat-header" data-repeat="true">
	<thead>
		<tr class="columns-header">
			<th>SKU</th>
			<th>Nama Produk</th>
			<th style="text-align: right;">Jumlah</th>
		</tr>
	</thead>
	<tbody>
		<!-- Konten tabel multi-halaman -->
	</tbody>
</table>
```

### Fitur Otomatis Tabel

- **Preservasi Header Multi-Baris:** Struktur `<thead>` kompleks dengan atribut `colspan` diduplikasi utuh pada setiap potongan halaman.
- **Pencetakan Footer (`<tfoot>`):** `<tfoot>` dicetak rapi pada segmen terakhir tabel.
- **Proteksi Baris Terpotong:**
  ```css
  tr {
  	break-inside: avoid;
  }
  ```

---

## 2. Kelanjutan Sel Rowspan Antar Halaman

Pada browser biasa, sel tabel dengan `rowspan="5"` yang terpotong antar halaman menyebabkan pergeseran kolom karena sel penahan tertinggal di halaman sebelumnya.

Printedjs mengatasinya secara otomatis dengan membuat sel kelanjutan sintetis ketika `class="repeat-rowspan"` atau `data-repeat="true"` diaktifkan pada tabel, serta mempertahankan teks label kategori antar pemisah halaman saat `data-repeat-content="true"` disematkan pada sel:

```html
<table class="repeat-header repeat-rowspan" data-repeat="true">
	<thead>
		<tr>
			<th>Subsistem</th>
			<th>Modul Engine</th>
			<th>Target Verifikasi</th>
			<th>Status</th>
		</tr>
	</thead>
	<tbody>
		<tr>
			<!-- Sel multi-baris dipotong rapi melintasi batas pemisah halaman dengan teks label kategori dipertahankan -->
			<td rowspan="5" class="category-cell" data-repeat-content="true">
				Table Fragmentation
			</td>
			<td>thead Duplication Pipeline</td>
			<td>Duplikasi header di lembar berikutnya</td>
			<td>Verified</td>
		</tr>
		<tr>
			<td>Row Integrity Guard</td>
			<td>Jaminan break-inside avoid atomik</td>
			<td>Verified</td>
		</tr>
		<!-- Batas halaman fisik terjadi melintasi sel multi-baris -->
		<tr>
			<td>Rowspan Continuation</td>
			<td>Sintesis sel kelanjutan otomatis</td>
			<td>Verified</td>
		</tr>
	</tbody>
</table>
```
