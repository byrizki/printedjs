Printedjs mendukung penuh properti CSS Fragmentation modern serta alias kompatibilitas `page-break-*`.

## Ringkasan Properti Break

| Properti Modern CSS | Ekuivalen Lama      | Nilai yang Didukung                                                  |
| :------------------ | :------------------ | :------------------------------------------------------------------- |
| `break-before`      | `page-break-before` | `auto`, `always`, `page`, `left`, `right`, `recto`, `verso`, `avoid` |
| `break-after`       | `page-break-after`  | `auto`, `always`, `page`, `left`, `right`, `recto`, `verso`, `avoid` |
| `break-inside`      | `page-break-inside` | `auto`, `avoid`, `avoid-page`                                        |

---

## Mencegah Pemotongan dalam Blok

Gunakan `break-inside: avoid` agar kartu, tabel, atau tanda tangan tidak terpotong:

```css
/* Mencegah elemen terpotong antar halaman */
.signature-block,
.kpi-card,
figure {
	break-inside: avoid;
}

/* Mencegah heading tertinggal sendiri di dasar halaman */
h1,
h2,
h3 {
	break-after: avoid;
}
```

## Facing Spreads & Halaman Kosong Otomatis

Pada pencetakan buku bolak-balik (duplex), bab baru biasanya wajib dimulai pada **halaman kanan (recto / ganjil)**.

Jika bab sebelumnya berakhir pada halaman kanan (Halaman 5), Printedjs otomatis menyisipkan **halaman kosong (blank page)** (Halaman 6) agar bab baru dimulai tepat pada halaman kanan (Halaman 7):

```css
.major-chapter {
	/* Memaksa bab baru mulai pada halaman kanan */
	break-before: right; /* atau 'recto' */
}

/* Beri gaya khusus untuk halaman kosong otomatis */
@page :blank {
	@top-left {
		content: none;
	}
	@bottom-right {
		content: none;
	}
}
```

### Nilai Break untuk Spread

- `break-before: left` / `verso` — Memaksa konten ke halaman kiri (genap).
- `break-before: right` / `recto` — Memaksa konten ke halaman kanan (ganjil).
- `break-after: left` / `right` — Menjaga paritas setelah bagian tertentu selesai.

## Kontrol Widow & Orphan

Cegah baris teks menggantung di batas halaman:

```css
p {
	orphans: 2; /* Jumlah baris minimum di dasar halaman sebelumnya */
	widows: 2; /* Jumlah baris minimum di awal halaman berikutnya */
}
```
