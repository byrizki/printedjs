Printedjs mengimplementasikan fitur tipografi lanjutan dari W3C Generated Content for Paged Media (GCPM) dan CSS Multi-column Layout, termasuk footnote di dasar halaman dan aliran kolom seimbang.

## 1. W3C Footnote (`float: footnote`)

Footnote memungkinkan catatan inline dipindahkan secara otomatis ke area catatan kaki di dasar halaman yang bersangkutan.

### Markup HTML & Gaya CSS

```html
<p>
	Latensi komunikasi microservice diuji pada 10.000 request
	<span class="footnote"
		>Pengujian dilakukan pada cluster Kubernetes v1.31 Linux kernel 6.12 dengan prosesor
		AMD EPYC.</span
	>
	dalam beban puncak.
</p>
```

```css
span.footnote {
	float: footnote;
	font-size: 8pt;
	color: #64748b;
	line-height: 1.4;
}

@page {
	@footnote {
		border-top: 1px solid #cbd5e1;
		padding-top: 8px;
		margin-top: 14px;
	}
}
```

## 2. Layout Multi-Kolom (`columns`)

Printedjs mendukung layout multi-kolom CSS dengan penyeimbangan tinggi kolom otomatis:

```css
.editorial-columns {
	column-count: 2; /* atau 'columns: 2;' */
	column-gap: 18mm;
	column-rule: 1px solid #e2e8f0;
	column-fill: balance; /* Otomatis menyeimbangkan tinggi kolom */
}

/* Membentang elemen melintasi seluruh kolom */
.editorial-columns .full-width-figure {
	column-span: all;
	margin: 16px 0;
	break-inside: avoid;
}
```

## 3. Proteksi Pemotongan Rumus (`mathPlugin`)

Notasi matematika dari KaTeX, MathJax, atau MathML sering rusak jika terpotong batas halaman. `mathPlugin` di Printedjs otomatis melindungi formula agar tidak terbelah:

```css
.katex-display,
mjx-container[display="true"],
math[display="block"] {
	break-inside: avoid;
}
```
