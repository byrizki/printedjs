Spesifikasi **CSS Paged Media Module** dari W3C mendefinisikan bagaimana konten web diformat, dipotong, dan diberi gaya ke dalam lembar halaman fisik.

Printedjs mengimplementasikan standar CSS Paged Media secara langsung di browser modern menggunakan parsing CSS standar dan pemotongan DOM Range.

::feature-preview{feature="summary"}
::

## Preset Standar (`standardPreset()`)

Semua plugin layout inti dibundel di `@printedjs/plugins` dan dapat dimuat bersama menggunakan `standardPreset()`:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

const renderer = createRenderer({
	target: document.querySelector("#preview")!,
	plugins: standardPreset(), // Memuat semua plugin Paged Media standar
});
```

## Spesifikasi & Plugin yang Didukung

| Spesifikasi / Kemampuan       | Nama Plugin              | Selektor & Deklarasi CSS Utama                                         |
| :---------------------------- | :----------------------- | :--------------------------------------------------------------------- |
| **Geometri Halaman & Margin** | `pageRulesPlugin`        | `@page`, `size`, `margin`, `bleed`, `marks: crop cross`                |
| **16 Margin Box**             | `generatedContentPlugin` | `@top-left`, `@top-center`, `@bottom-right`, margin tracks             |
| **Semantik Break**            | `breaksPlugin`           | `break-before`, `break-after`, `break-inside: avoid`, `page-break-*`   |
| **Paritas Blank Page**        | `breaksPlugin`           | `break-before: left / right / recto / verso`                           |
| **Named String**              | `stringsPlugin`          | `string-set: title content()`, `content: string(title)`                |
| **Running Element**           | `runningHeadersPlugin`   | `position: running(header)`, `content: element(header)`                |
| **Counter Halaman**           | `countersPlugin`         | `counter(page)`, `counter(pages)`, `target-counter()`, `counter-reset` |
| **Footnote**                  | `footnotesPlugin`        | `float: footnote`, `@footnote`, pemotongan multi-halaman footnote      |
| **Layout Multi-Kolom**        | `columnsPlugin`          | `columns`, `column-count`, `column-gap`, `column-fill: balance`        |
| **Widow & Orphan**            | `widowsOrphansPlugin`    | `widows: 2`, `orphans: 2`                                              |
| **Proteksi Rumus Matematika** | `mathPlugin`             | Pencegahan break pada KaTeX, MathJax, `<math>`                         |
| **Hyphenation**               | `hyphenationPlugin`      | Preservasi soft hyphen dan normalisasi pemenggalan kata                |
| **Bookmark Dokumen**          | `bookmarksPlugin`        | Ekstraksi hierarki heading untuk bookmark PDF                          |
| **Tampilan Reader**           | `pageViewsPlugin`        | Tampilan single-page, dua halaman spread, dan flipbook 3D              |

## Panduan Fitur

- [Aturan Halaman & Margin](/features/page-rules-and-margins) — Ukuran lembar, bleed, crop mark, dan 16 margin box.
- [Break Halaman](/features/page-breaks) — Kontrol pemutusan halaman, aturan avoid, dan penyisipan halaman kosong recto/verso.
- [Header & Footer](/features/headers-footers-strings) — Header dinamis dengan string-set dan running element.
- [Counter & Daftar Isi](/features/counters-and-toc) — Format penomoran, angka Romawi, dan daftar isi otomatis dengan dot leaders.
- [Tabel & Rowspan](/features/tables-and-splits) — Pemisahan tabel multi-halaman, perulangan header, dan kelanjutan rowspan.
- [Footnote & Kolom](/features/footnotes-and-columns) — Footnote di dasar halaman dan aliran kolom seimbang.
- [Flipbook & Reader Views](/features/reader-views-and-export) — Tampilan spread, flipbook 3D, drawer navigasi, dan cetak langsung.
