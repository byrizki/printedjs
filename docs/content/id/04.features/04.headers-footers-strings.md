Pada dokumen multi-halaman, running header dan footer menampilkan judul bab atau metadata dokumen di bagian atas atau bawah setiap lembar halaman.

Printedjs menyediakan dua cara untuk mencapainya:

1. **Named String (`string-set` & `string()`):** Mengambil teks dari judul di body dan mencetaknya ke `@top-left`, `@top-right`, dll.
2. **Running Element (`position: running()` & `element()`):** Memindahkan elemen HTML lengkap (logo, badge, atau tabel) langsung ke margin box.

---

## 1. Named String (`string-set`)

Properti `string-set` menangkap teks dari elemen dokumen dan menyimpannya ke dalam variabel:

```css
/* 1. Ambil teks judul saat h2 muncul */
h2.section-heading {
	string-set: current-section content();
}

/* 2. Tampilkan string di margin box kanan atas */
@page {
	size: A4;
	margin: 25mm 20mm;

	@top-right {
		content: string(current-section);
		font-size: 8.5pt;
		font-weight: 500;
		color: #64748b;
	}
}
```

## 2. Running Element (`position: running`)

Jika header memerlukan logo perusahaan, badge bergaya, atau tata letak multi-baris, gunakan running element:

```html
<!-- Template header di dalam body HTML -->
<header class="doc-header">
	<div class="header-logo">
		<img src="/logo.svg" alt="Logo Perusahaan" width="120" />
	</div>
	<div class="header-meta">
		<span class="confidential-badge">RAHASIA</span>
		<span class="report-id">Q4-2026-AUDIT</span>
	</div>
</header>

<main>
	<h1>Ringkasan Eksekutif</h1>
	<p>Isi dokumen mengalir ke berbagai halaman...</p>
</main>
```

```css
/* 1. Keluarkan elemen dari flow normal dan daftarkan ke slot running */
.doc-header {
	position: running(pageHeader);
}

/* 2. Tempelkan elemen ke margin box yang diinginkan */
@page {
	size: A4;
	margin-top: 35mm; /* Sediakan ruang untuk header */

	@top-center {
		content: element(pageHeader);
	}
}
```
