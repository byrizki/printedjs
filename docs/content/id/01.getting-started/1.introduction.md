**Printedjs** adalah engine TypeScript modern dan berperforma tinggi untuk rendering dokumen berhalaman (paginated) secara browser-native. Dirancang dari nol sebagai penerus modular dan tangguh untuk menggantikan Paged.js monolitik yang sudah usang.

Printedjs mengubah HTML dan CSS standar menjadi dokumen siap cetak yang tertata rapi ke dalam halaman fisik, mengimplementasikan standar W3C CSS Paged Media Module secara langsung di browser web modern, runtime headless otomatisasi, serta aplikasi native lintas platform.

## Perbandingan Printedjs vs. Paged.js

Printedjs dirancang sebagai penerus modern dan modular untuk Paged.js. Jika Paged.js memelopori implementasi W3C CSS Paged Media di browser web, Printedjs menyempurnakannya dengan mengatasi berbagai tantangan arsitektur headless, ketahanan loop pagination, pemotongan tabel kompleks, isolasi memori, serta runtime native lintas platform:

| Kemampuan & Konteks Arsitektural                                                                                                |   Printedjs    |     Paged.js      |
| :------------------------------------------------------------------------------------------------------------------------------ | :------------: | :---------------: |
| **Standar Inti W3C CSS Paged Media**<br/>Ukuran `@page`, margin, orientasi, bleed, dan tanda potong (crop marks).               |   ✓ Lengkap    |     ✓ Lengkap     |
| **16 Margin Box & Counter Halaman**<br/>Geometri margin box standar (`@top-center`, `@bottom-right`), penomoran halaman.        |   ✓ Lengkap    |     ✓ Lengkap     |
| **Named String & Running Header**<br/>Header dan footer dinamis melalui CSS `string-set` dan `string()`.                        |   ✓ Lengkap    |     ✓ Lengkap     |
| **Footnote (`float: footnote`)**<br/>Printedjs menambahkan pemotongan kelanjutan footnote di antara pemisah halaman.            |   ✓ Lanjutan   |      ✓ Dasar      |
| **Perulangan Header & Footer Tabel**<br/>Printedjs menyinkronkan lebar kolom secara matematis agar baris tidak bergeser.        |   ✓ Lanjutan   |      ✓ Dasar      |
| **Pemotongan Lanjutan Tabel `rowspan`**<br/>Printedjs memotong sel multi-baris secara matematis tepat di batas halaman fisik.   |   ✓ Lengkap    |         ✗         |
| **Paritas Halaman Kosong Spreads**<br/>Otomatis menyisipkan halaman kosong verso untuk menjaga paritas buku cetak fisik.        |   ✓ Otomatis   |     ⚠️ Manual     |
| **Arsitektur Core Terpisah**<br/>AST dan state machine terpisah dari DOM; layout dijalankan via `@printedjs/browser`.           |   ✓ Lengkap    | ✗ (Kebutuhan DOM) |
| **Proteksi Infinite Loop (`ProgressGuard`)**<br/>Mendeteksi pass tanpa kemajuan; mencegah tab browser freeze dan CI hang.       |    ✓ Bawaan    |         ✗         |
| **Isolasi Surface & Pembersihan Memori**<br/>Surface `iframe`/`root` terisolasi dengan jaminan teardown bersih via `destroy()`. |   ✓ Lengkap    |     ⚠️ Manual     |
| **Native Headless WebView**<br/>WebView offscreen native dan vector PDF untuk React Native dan .NET 8+.                         |   ✓ Lengkap    |         ✗         |
| **Peralatan CLI Headless**<br/>CLI Printedjs mendukung driver headless webview bawaan, Playwright, dan Puppeteer.               | ✓ Multi-Engine | ✓ Puppeteer saja  |
| **Presentasi 3D Flipbook**<br/>Engine pembalik halaman 3D interaktif via `@printedjs/plugin-page-flip`.                         | ✓ Mikro-plugin |         ✗         |
| **Dukungan Penuh TypeScript**<br/>100% kontrak bertipe ketat, autocompletion IDE presisi, tanpa kebocoran `any`.                |   ✓ Lengkap    |   ⚠️ Deklarasi    |
| **Ukuran Bundle Ringan**<br/>Mikro-plugin modular tree-shakeable; 78% lebih hemat bandwidth.                                    |   ✓ (~52 KB)   |     (~240 KB)     |

## Showcase Performa & Benchmark Engine

Untuk memberikan gambaran performa yang transparan dan dapat diverifikasi, Printedjs diuji secara langsung bersama compiler typesetting native, polyfill browser konvensional, serta driver otomatisasi headless saat memproses dokumen laporan keuangan 10 halaman yang memuat perulangan header tabel, running header/footer, footnote, dan penomoran halaman dinamis:

### Benchmark Ekspor PDF End-to-End (Dokumen 10 Halaman)

| Engine / Pipeline              | Runtime Dasar           | Waktu Eksekusi | Memori Peak RSS | Ukuran File PDF |
| :----------------------------- | :---------------------- | :------------: | :-------------: | :-------------: |
| **Typst** (`v0.14.2`)          | Biner Native Rust       |   **~94 ms**   |   **~39 MB**    |     132 KB      |
| **Printedjs Headless WebView** | Engine On-Device Native |  **~468 ms**   |     ~134 MB     |     792 KB      |
| **Printedjs (Playwright)**     | Node.js + Chromium      |  **~880 ms**   |     ~184 MB     |    **61 KB**    |
| **Printedjs (Puppeteer)**      | Node.js + Chromium CDP  |   **~1,0 s**   |     ~192 MB     |     156 KB      |
| **Paged.js Polyfill**          | Puppeteer + Reflow DOM  |     ~1,0 s     |     ~191 MB     |     156 KB      |

### Efisiensi Layout Browser & Ukuran Bundle

Pada aplikasi web client-side, Printedjs memberikan penghematan memori dan ukuran bundle yang signifikan dibanding Paged.js lama:

- **Ukuran Bundle 60.3% Lebih Ringan**: `@printedjs/minimal` hanya berukuran **52,2 KB gzip** (dibandingkan Paged.js **99,0 KB gzip / 504 KB non-minified**), mempercepat parsing dan hidrasi halaman.
- **Virtualisasi Halaman (`virtualizePages`)**: Viewer dokumen browser hanya merender halaman yang terlihat di viewport, menjaga scroll tetap halus di 60 FPS pada dokumen dengan 300+ halaman tanpa membebani DOM.
