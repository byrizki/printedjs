Demo ini menampilkan performa `@printedjs/minimal` dalam merender dokumen multi-halaman kompleks secara langsung:

- **16 CSS Margin Boxes**: Running header, judul seksi dinamis melalui `string-set()`, dan penomoran halaman (`counter(page) of counter(pages)`).
- **Table of Contents Dinamis**: Dot leader otomatis dengan penomoran halaman target menggunakan `target-counter()`.
- **Tabel Multi-Halaman**: Pengulangan `<thead>` di tiap halaman, pemotongan sel `rowspan`, dan perhitungan subtotal di batas halaman.
- **Catatan Kaki (Footnotes) & Callout**: Penempatan catatan kaki otomatis di bagian bawah page box.
