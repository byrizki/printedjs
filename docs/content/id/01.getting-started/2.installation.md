Printedjs menyediakan berbagai opsi instalasi sesuai kebutuhan arsitektur Anda. Anda bisa menginstal package modular TypeScript untuk bundler modern, memuat script mandiri langsung di browser, atau memakai CLI dan binding native untuk mobile maupun desktop.

## Package Modular Web (Bundler)

Untuk aplikasi web modern berbasis Vite, Next.js, Nuxt, Webpack, atau Rollup, instal browser renderer dan preset plugin:

```bash [pnpm]
pnpm add @printedjs/browser @printedjs/plugins
```

```bash [npm]
npm install @printedjs/browser @printedjs/plugins
```

```bash [yarn]
yarn add @printedjs/browser @printedjs/plugins
```

### Package Tambahan (Opsional)

```bash
# Kontrak engine core terpisah, state machine, dan perkakas AST CSS
pnpm add @printedjs/core

# Overlay inspector visual non-layout dan trace collector
pnpm add -D @printedjs/devtools

# Lapisan kompatibilitas polyfill untuk browser lama
pnpm add @printedjs/polyfill
```

## Bundle Minimal Mandiri (CDN / Script Tag)

Jika Anda membutuhkan solusi instan tanpa build step (seperti polyfill Paged.js lama), gunakan `@printedjs/minimal`:

```html
<!-- Muat script standalone Printedjs -->
<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>
```

Bundle minimal ini secara otomatis mendeteksi stylesheet bertanda `@page`, me-render dan membagi dokumen ke dalam halaman fisik saat `DOMContentLoaded`, serta menyediakan kompatibilitas `window.Paged` untuk script yang sudah ada.

## Headless PDF Generation CLI

Untuk meng-compile file HTML dan CSS Paged Media langsung menjadi PDF vektor dari terminal, CI/CD pipeline, atau backend service:

```bash [pnpm]
pnpm add -D @printedjs/cli
```

```bash [npm]
npm install -D @printedjs/cli
```

Atau jalankan langsung tanpa instalasi lokal lewat `npx` / `pnpm dlx`:

```bash
pnpm dlx @printedjs/cli render document.html -o output.pdf
```

Secara default, CLI memakai engine native `webview` bawaan (tanpa perlu download browser tambahan). Jika Anda lebih memilih driver otomatisasi browser, instal Playwright atau Puppeteer:

```bash
# Driver Playwright
pnpm add -D playwright
pnpm dlx playwright install chromium

# Driver Puppeteer
pnpm add -D puppeteer
```

## Native Headless Webview

### React Native (iOS & Android)

Untuk aplikasi React Native yang membutuhkan pembuatan PDF di latar belakang:

```bash
pnpm add @printedjs/headless-webview
```

Untuk iOS, pastikan pod telah terinstal:

```bash
cd ios && pod install
```

### .NET 8 / MAUI / Unity (NuGet)

Untuk sistem backend C# dan ekosistem .NET:

```bash [.NET CLI]
dotnet add package PrintedJs.HeadlessWebView
```

```xml [Package Manager]
<PackageReference Include="PrintedJs.HeadlessWebView" Version="0.2.2" />
```

## Verifikasi Instalasi

Verifikasi bahwa instalasi berhasil dengan memeriksa versi CLI:

```bash
pnpm printedjs --version
```
