Mulai menggunakan Printedjs dalam waktu kurang dari lima menit. Panduan ini mencakup rendering programatik di browser, integrasi HTML statis tanpa konfigurasi, dan rendering PDF headless via CLI.

## 1. Rendering Programatik di Browser

Gunakan `@printedjs/browser` dan `@printedjs/plugins` untuk me-render dokumen berhalaman langsung di dalam aplikasi web Anda:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

// 1. Tentukan elemen container target di DOM Anda
const target = document.querySelector("#preview-container")!;

// 2. Buat instance renderer dengan mode isolasi dan plugin preset
const renderer = createRenderer({
	target,
	isolation: "root", // atau "iframe" untuk isolasi total style dan script
	plugins: standardPreset(),
});

// 3. Render konten HTML beserta aturan CSS Paged Media
const result = await renderer.render({
	content: {
		html: `
      <style>
        @page {
          size: A4;
          margin: 25mm 20mm;

          @top-left {
            content: "Panduan Mulai Cepat Printedjs";
            font-family: sans-serif;
            font-size: 9pt;
            color: #64748b;
          }

          @bottom-right {
            content: "Halaman " counter(page) " dari " counter(pages);
            font-family: sans-serif;
            font-size: 9pt;
            font-weight: 500;
          }
        }

        h1 {
          color: #0f172a;
          border-bottom: 2px solid #0284c7;
          padding-bottom: 8px;
        }

        p {
          line-height: 1.6;
          color: #334155;
        }
      </style>

      <h1>Halo, Printedjs!</h1>
      <p>Dokumen ini secara otomatis dibagi ke dalam halaman fisik lengkap dengan margin standar, running header, dan nomor halaman dinamis.</p>
    `,
	},
});

console.log(
	`Berhasil me-render ${result.pages.length} halaman dalam ${result.metrics.durationMs}ms`,
);

// 4. Bersihkan DOM tanpa residu jika sudah tidak diperlukan
// renderer.destroy();
```

## 2. Integrasi Drop-in HTML Statis (Tanpa Konfigurasi)

Jika Anda memiliki dokumen HTML statis atau mencari pengganti drop-in untuk `paged.polyfill.js`:

```html
<!doctype html>
<html lang="id">
	<head>
		<meta charset="UTF-8" />
		<title>Dokumen Siap Cetak Saya</title>
		<!-- 1. Muat bundle minimal Printedjs -->
		<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>

		<style>
			@page {
				size: letter;
				margin: 1in;

				@bottom-center {
					content: "Halaman " counter(page);
					font-family: sans-serif;
					font-size: 10pt;
				}
			}

			.chapter {
				break-before: page;
			}
		</style>
	</head>
	<body>
		<h1>Bab 1: Pendahuluan</h1>
		<p>Konten langsung mengalir rapi ke halaman cetak saat DOMContentLoaded.</p>

		<div class="chapter">
			<h1>Bab 2: Konten Lanjutan</h1>
			<p>Otomatis dimulai pada halaman baru dengan penanganan break yang aman.</p>
		</div>

		<script>
			// Dengarkan event ketika pagination selesai
			window.addEventListener("printedjs:rendered", (e) => {
				console.log("Rendering dokumen selesai!", e.detail);
			});
		</script>
	</body>
</html>
```

## 3. Rendering PDF Headless via CLI

Untuk meng-compile file HTML menjadi file PDF vektor berkualitas tinggi langsung dari terminal:

```bash
# Render document.html menjadi document.pdf memakai engine native bawaan
pnpm printedjs render document.html -o document.pdf --format A4 --bleed 3mm

# Aktifkan watch mode untuk recompile otomatis saat file diedit
pnpm printedjs render document.html -o document.pdf --watch
```

## 4. Cetak & Ekspor PDF Langsung di Browser

Printedjs menyediakan helper bawaan untuk memicu dialog print browser secara bersih tanpa menampilkan elemen antarmuka browser:

```typescript
import { printDocument } from "@printedjs/browser";

// Buka dialog print browser dengan judul dokumen rapi dan tanpa artefak layar
await printDocument({
	target: window,
	pageTitle: "Laporan Keuangan Triwulan",
	cleanChrome: true,
});
```
