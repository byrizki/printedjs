Dokumen ini merangkum evolusi arsitektur, pencapaian teknis yang telah selesai, dan arah pengembangan masa depan untuk **Printedjs**.

## Jalur Pengembangan Teknis

### Jalur 1: Arsitektur Inti & Resiliensi

Membangun fondasi arsitektur core yang terpisah untuk mencegah browser freeze dan kebocoran memori.

| Milestone                  | Cakupan Package      | Fitur Utama                                                                                    | Status    |
| :------------------------- | :------------------- | :--------------------------------------------------------------------------------------------- | :-------- |
| **Pure Core Contracts**    | `@printedjs/core`    | Kontrak pagination core terpisah, CSS AST facade, pipeline plugin topologis.                   | `Selesai` |
| **Isolasi Surface**        | `@printedjs/browser` | Pemisahan bersih antara DOM aplikasi dan dokumen melalui `root` dan sandboxed `iframe`.        | `Selesai` |
| **Proteksi Infinite Loop** | `@printedjs/browser` | State machine `LayoutProgressGuard` mendeteksi zero-advance break token dan unbreakable block. | `Selesai` |
| **Paritas Halaman Kosong** | `@printedjs/browser` | Pembuatan halaman kosong fisik otomatis untuk `break-before: recto/verso` dan penjilidan buku. | `Selesai` |

### Jalur 2: Kepatuhan Standar CSS Paged Media

Dukungan penuh standar W3C CSS Paged Media untuk penerbitan dokumen kelas enterprise.

| Milestone                     | Cakupan Package                         | Fitur Utama                                                                                   | Status    |
| :---------------------------- | :-------------------------------------- | :-------------------------------------------------------------------------------------------- | :-------- |
| **16 CSS Margin Boxes**       | `@printedjs/plugins`                    | Margin box perimeter lengkap, running header, footer, dan kotak sudut.                        | `Selesai` |
| **Dynamic String Sets**       | `@printedjs/plugins`                    | `string-set` dan `content: string(...)` untuk judul bab/seksi dinamis di tiap halaman.        | `Selesai` |
| **Counter Multi-Sistem**      | `@printedjs/core`, `@printedjs/plugins` | Pemformatan `counter()` murni (`lower-roman`, `upper-alpha`, `decimal-leading-zero`) dan TOC. | `Selesai` |
| **Tabel Multi-Halaman**       | `@printedjs/plugins`                    | Pengulangan otomatis `<thead>` dan `<tfoot>`, pemotongan sel rowspan, dan subtotal.           | `Selesai` |
| **Mirrored Margins & Gutter** | `@printedjs/plugins`                    | Perhitungan `margin-inside`, `margin-outside`, dan binding gutter untuk geometri recto/verso. | `Selesai` |

### Jalur 3: Platform, CLI & Native Runtime

Memperluas pagination dokumen di luar browser biasa ke otomatisasi headless dan runtime native mobile/desktop.

| Milestone                           | Cakupan Package               | Fitur Utama                                                                               | Status    |
| :---------------------------------- | :---------------------------- | :---------------------------------------------------------------------------------------- | :-------- |
| **Headless PDF CLI**                | `@printedjs/cli`              | CLI produksi dengan auto-detection driver headless browser Playwright dan Puppeteer.      | `Selesai` |
| **Cross-Platform Headless WebView** | `@printedjs/headless-webview` | Driver native WebKit/Wry untuk React Native iOS/Android dan runtime lintas platform .NET. | `Selesai` |
| **Matriks Visual Parity**           | Test Suite                    | 90 test case visual regression otomatis di Chromium, Firefox, dan WebKit pada CI.         | `Selesai` |
| **Bundle Minimal Siap Pakai**       | `@printedjs/minimal`          | Bundle distribusi all-in-one 52 KB gzipped dengan auto-detection stylesheet `@page`.      | `Selesai` |

### Jalur 4: Ekosistem Reader & Pengalaman Developer

Tools dan lapisan presentasi untuk melihat preview, menginspeksi, dan membaca dokumen yang telah dipaginasi.

| Milestone                   | Cakupan Package               | Fitur Utama                                                                                 | Status    |
| :-------------------------- | :---------------------------- | :------------------------------------------------------------------------------------------ | :-------- |
| **Overlay DevTools**        | `@printedjs/devtools`         | Overlay visual non-layout yang menampilkan dimensi page box, batas bleed, dan trace render. | `Selesai` |
| **Spread & Mode Reader**    | `@printedjs/plugins`          | Mode membaca two-page spread dengan bayangan lipatan buku (spine fold).                     | `Selesai` |
| **3D Interactive Flipbook** | `@printedjs/plugin-page-flip` | Animasi pembalikan halaman 3D berbasis fisika dengan sintesis efek suara kertas.            | `Selesai` |
| **Drawer TOC Interaktif**   | `@printedjs/plugins`          | Panel navigasi dinamis yang terhubung langsung ke judul halaman dan anchor dokumen.         | `Selesai` |

## Rencana Masa Depan

### 1. Streaming Pagination Menggunakan Web Worker

- Memindahkan parsing CSS AST dan pengukuran geometri teks ke Web Worker.
- Melakukan streaming halaman secara progresif melalui WebSocket atau Chunked HTTP untuk rendering batch skala besar.

### 2. Output Dokumen PDF/A & Tagged PDF

- Pembuatan langsung metadata PDF/A, accessibility tree tagged PDF (WCAG 2.1), dan Table of Contents interaktif berbasis hyperlink pada CLI rendering.

### 3. Viewer Dokumen Terakselerasi GPU / Canvas

- Merender layout halaman yang telah dihitung melalui HTML5 Canvas atau WebGPU untuk pan/zoom 60fps yang mulus pada katalog dan pembaca e-book.
