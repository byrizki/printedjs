#title
Rendering dokumen berhalaman modern dan performa tinggi.

#description
`Printedjs` mengubah HTML dan CSS standar menjadi dokumen siap cetak berhalaman rapi dengan kepatuhan penuh standar CSS Paged Media, arsitektur core terpisah, perlindungan infinite loop, dan pembuatan PDF native lintas platform.
