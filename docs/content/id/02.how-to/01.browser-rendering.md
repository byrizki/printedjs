Package `@printedjs/browser` menyediakan engine rendering level DOM utama, adapter pengukuran range, abstraksi isolasi surface, serta lifecycle teardown deterministik.

## Membuat Instance Renderer

Inisialisasi renderer memakai fungsi factory `createRenderer`:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

const targetContainer = document.querySelector("#preview")!;

const renderer = createRenderer({
	target: targetContainer,
	isolation: "root", // "root" | "iframe"
	pagedjsCompatible: false, // Ubah ke true untuk class legacy .pagedjs_*
	plugins: standardPreset(),
});
```

### Opsi Konfigurasi

| Opsi                | Tipe                 | Default     | Deskripsi                                                                  |
| :------------------ | :------------------- | :---------- | :------------------------------------------------------------------------- |
| `target`            | `HTMLElement`        | **Wajib**   | Elemen DOM tempat halaman-halaman hasil render akan di-mount.              |
| `isolation`         | `"root" \| "iframe"` | `"root"`    | Mode isolasi surface (container langsung vs sandboxed iframe).             |
| `plugins`           | `PrintedjsPlugin[]`  | `[]`        | Daftar plugin yang akan dieksekusi sepanjang hook lifecycle.               |
| `pagedjsCompatible` | `boolean`            | `false`     | Jika true, menghasilkan class CSS ganda (`.printedjs_*` dan `.pagedjs_*`). |
| `baseUrl`           | `string`             | `undefined` | Base URL untuk me-resolve file aset relatif dan aturan `@import`.          |

## Mode Isolasi Surface

Printedjs menyediakan dua pilihan isolasi surface:

| Kemampuan              | Root Surface (`isolation: "root"`)                     | Iframe Surface (`isolation: "iframe"`)                |
| :--------------------- | :----------------------------------------------------- | :---------------------------------------------------- |
| **Target DOM**         | Elemen container DOM langsung                          | `<iframe>` sandboxed same-origin                      |
| **Throughput**         | Throughput render tercepat (tanpa overhead iframe)     | Konteks terisolasi dengan layout mandiri              |
| **Batas CSS**          | Di-scope oleh wrapper `.printedjs_pages`               | Batas penuh CSS dan script terisolasi                 |
| **Penggunaan Terbaik** | Single-page application & template internal terpercaya | HTML dari user luar, aplikasi dengan CSS reset global |

### 1. Root Surface (`isolation: "root"`)

Langsung menyematkan wrapper halaman ke dalam elemen target. Direkomendasikan untuk aplikasi single-page (SPA), editor dokumen interaktif, dan template terpercaya di mana performa rendering maksimal diutamakan.

### 2. Iframe Surface (`isolation: "iframe"`)

Membuat elemen `<iframe>` terisolasi di dalam target dan me-render dokumen di dalam konteks browsing iframe tersebut. Hal ini menjamin style dari aplikasi host (seperti reset Tailwind atau Bootstrap) tidak akan merusak layout cetak, dan style dokumen tidak akan bocor ke aplikasi utama Anda.

## Menjalankan Rendering

Panggil method `renderer.render()` dengan konten HTML dan stylesheet opsional:

```typescript
const result = await renderer.render({
	content: {
		html: "<article><h1>Laporan Tahunan</h1><p>...</p></article>",
		stylesheets: ["/css/print-theme.css"],
	},
	baseUrl: "https://example.com/assets/",
});

console.log(
	`Render selesai: ${result.pages.length} halaman dalam ${result.metrics.durationMs}ms`,
);
```

### Struktur Objek RenderResult

Hasil render mengembalikan objek `RenderResult` berisi daftar halaman dan metrik performa:

```typescript
interface RenderResult {
	pages: PageResult[];
	metrics: {
		durationMs: number;
		parseDurationMs: number;
		layoutDurationMs: number;
		pageCount: number;
	};
}
```

## Teardown Deterministik (`renderer.destroy()`)

Salah satu keunggulan utama Printedjs dibandingkan engine lama adalah pembersihan DOM yang bersih dan terjamin. Memanggil `destroy()` akan mengembalikan kondisi DOM host tanpa residu:

```typescript
// Menghapus seluruh elemen mounted, observer, event listener, dan style sheet yang diinjeksikan:
renderer.destroy();
```

Tanpa node DOM tertinggal, tanpa style stylesheet bocor, dan bebas memory leak.

## Memicu Print PDF Langsung

Gunakan helper `printDocument` untuk membuka dialog print browser dengan pembersihan otomatis elemen layar (UI chrome):

```typescript
import { printDocument } from "@printedjs/browser";

await printDocument({
	target: renderer.surface.window ?? window,
	pageTitle: "Sertifikat Resmi",
	cleanChrome: true,
});
```
