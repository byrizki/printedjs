`@printedjs/cli` meng-compile dokumen HTML dan CSS Paged Media menjadi dokumen PDF vektor berkualitas tinggi dan presisi. Package ini mendukung WebView native off-screen (default bawaan) serta driver otomatisasi headless browser (Playwright dan Puppeteer).

## Instalasi

Instal sebagai dependency dev di project Anda atau secara global:

```bash
pnpm add -D @printedjs/cli
# atau npm install -D @printedjs/cli
```

### Engine Browser Opsional

Secara default, engine `webview` menggunakan binary native `headless-webview` bawaan sehingga tidak memerlukan download browser eksternal apa pun.

Jika Anda ingin memakai driver otomatisasi browser, instal salah satu:

```bash
# Driver Playwright opsional
pnpm add -D playwright
pnpm dlx playwright install chromium

# Driver Puppeteer opsional
pnpm add -D puppeteer
```

## Penggunaan Command Line

### Kompilasi PDF Dasar

```bash
# Compile file HTML ke PDF memakai engine native webview default
pnpm printedjs render document.html -o document.pdf

# Menentukan format kertas, orientasi, dan bleed
pnpm printedjs render invoice.html -o invoice.pdf --format A4 --bleed 3mm
```

### Memilih Engine Rendering

```bash
# Engine webview headless native default (ringan, tanpa download browser)
pnpm printedjs render doc.html -o doc.pdf --engine webview

# Engine Playwright
pnpm printedjs render doc.html -o doc.pdf --engine playwright

# Engine Puppeteer
pnpm printedjs render doc.html -o doc.pdf --engine puppeteer
```

### Menunggu Konten Asinkron & Pagination

```bash
# Tunggu hingga pagination Printed.js selesai sebelum mengekspor PDF
pnpm printedjs render report.html -o report.pdf --wait-printedjs

# Tunggu hingga eksekusi polyfill Paged.js legacy selesai
pnpm printedjs render report.html -o report.pdf --wait-pagedjs --pagedjs-compatible

# Tunggu ekspresi JavaScript kustom atau rendering chart dinamis
pnpm printedjs render dashboard.html -o dashboard.pdf --wait-for "window.chartsRendered === true"
```

### Watch Mode untuk Pembuatan Dokumen Interaktif

```bash
# Otomatis compile ulang ketika file HTML atau CSS mengalami perubahan
pnpm printedjs render report.html -o report.pdf --watch
```

## Lingkungan Headless Linux & Docker

Engine native `webview` berbasis WebKitGTK dan GTK 3 pada Linux yang membutuhkan display connection aktif. Di lingkungan headless (seperti Docker container, CI runner, atau server cloud), jalankan melalui `xvfb-run`:

```bash
xvfb-run -a pnpm printedjs render doc.html -o doc.pdf
```

Sebagai alternatif, Anda juga bisa memakai flag `--engine playwright` atau `--engine puppeteer` jika Chromium sudah tersedia di container.

## Referensi Opsi CLI

```text
Usage: printedjs render <input> [opsi]

Argumen:
  <input>                     Path file atau URL dokumen HTML sumber

Opsi:
  -o, --output <file>         Lokasi file output PDF (default: output.pdf)
  -f, --format <format>       Format ukuran kertas (A4, Letter, Legal, A3, dll.)
  -b, --bleed <dimension>     Dimensi bleed (contoh: 3mm, 0.125in)
  -e, --engine <engine>       Engine rendering: webview | playwright | puppeteer (default: webview)
  --wait-for <expr>           Tunggu ekspresi JS bernilai truthy sebelum mengekspor PDF
  --wait-printedjs            Tunggu hingga pagination Printed.js selesai sebelum membuat PDF
  --wait-pagedjs              Tunggu hingga pagination Paged.js selesai sebelum membuat PDF
  -w, --watch                 Watch mode: otomatis compile ulang saat file berubah
  --pagedjs-compatible        Menghasilkan class ganda Printedjs dan legacy Paged.js
  --no-pagedjs-compatible     Hanya menghasilkan class modern Printedjs (default)
  --timeout <ms>              Timeout render dan pagination dalam milidetik (default: 30000)
  -h, --help                  Tampilkan informasi bantuan
  -v, --version               Tampilkan versi
```

## API Programatik Node.js

Anda dapat memanggil engine rendering CLI langsung dari aplikasi Node.js, serverless function, atau microservice backend:

```typescript
import { renderPdf } from "@printedjs/cli";

const result = await renderPdf({
	input: "./reports/quarterly.html",
	output: "./dist/quarterly.pdf",
	format: "A4",
	bleed: "3mm",
	engine: "webview", // atau "playwright" | "puppeteer"
	waitPrintedjs: true, // atau waitFor: "window.isReady === true"
	timeoutMs: 30000,
});

console.log(
	`Render selesai: ${result.pageCount} halaman dalam ${result.durationMs.toFixed(1)}ms`,
);
console.log(`File tersimpan di: ${result.outputPath}`);
```

## Binary Desktop Mandiri (`headless-webview`)

CLI juga menyertakan binary native siap pakai untuk Windows (`headless-webview.exe`), macOS, dan Linux yang ditenagai oleh Wry. Anda dapat menjalankannya langsung:

```bash
headless-webview input.html -o output.pdf --wait-for "window.isReady === true" --format A4
```
