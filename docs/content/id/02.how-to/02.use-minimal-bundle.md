`@printedjs/minimal` adalah distribusi all-in-one dari Printedjs. Package ini menggabungkan core engine, layout adapter browser, preset plugin standar, dan polyfill ke dalam satu file script ringan (`printedjs.min.js`, ~200 KB minified / ~52 KB gzip).

Dirancang khusus untuk website statis, generator dokumentasi, server laporan, serta sebagai pengganti langsung (drop-in) bagi `paged.polyfill.js`.

## Cara Penggunaan Dasar

Cukup masukkan tag script ke dalam `<head>` atau di akhir `<body>`:

```html
<!doctype html>
<html lang="id">
	<head>
		<meta charset="UTF-8" />
		<title>Spesifikasi Dokumen Perusahaan</title>
		<!-- Muat Printedjs Minimal -->
		<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>

		<style>
			@page {
				size: A4;
				margin: 20mm;

				@bottom-right {
					content: "Halaman " counter(page) " dari " counter(pages);
					font-family: sans-serif;
					font-size: 8.5pt;
				}
			}

			h1 {
				break-after: avoid;
			}

			.section-break {
				break-before: page;
			}
		</style>
	</head>
	<body>
		<h1>Ringkasan Laporan</h1>
		<p>Konten langsung dipaginasi secara otomatis saat halaman web dimuat.</p>

		<div class="section-break">
			<h2>Ringkasan Finansial</h2>
			<p>Bagian ini otomatis dimulai pada halaman cetak baru.</p>
		</div>
	</body>
</html>
```

## Inisialisasi Otomatis (Auto-Init)

Saat `@printedjs/minimal` dimuat:

1. Script memeriksa kesiapan dokumen. Jika halaman masih proses loading, script memasang listener pada event `DOMContentLoaded`.
2. Script mem-parse seluruh tag `<style>` inline dan `<link rel="stylesheet">` eksternal untuk mencari aturan CSS `@page`.
3. Jika aturan `@page` atau selektor paged media ditemukan, proses pagination otomatis dimulai.
4. Struktur DOM awal digantikan dengan container halaman `.printedjs_page` yang terstandarisasi.

## Event Lifecycle DOM

Printedjs memancarkan custom event standar sehingga Anda bisa mengontrol animasi loading, spinner, atau automated testing:

```javascript
// Dijalankan saat pagination selesai dan seluruh halaman telah di-mount
window.addEventListener(
	"printedjs:rendered",
	(event) => {
		console.log("Pagination selesai!");
		console.log("Jumlah halaman:", event.detail.pages.length);
		console.log("Durasi proses:", event.detail.metrics.durationMs);

		// Contoh: hilangkan spinner loading
		document.getElementById("loader")?.remove();
	},
	{ once: true },
);

// Tetap memancarkan event pagedjs:rendered untuk backward compatibility:
window.addEventListener("pagedjs:rendered", () => {
	console.log("Event kompatibilitas legacy terpanggil");
});
```

## Mencegah Elemen Tertentu Dipaginasi

Jika Anda memiliki elemen navigasi mengambang (floating toolbar, tombol aksi cetak, atau monitor debug) yang tidak boleh dimasukkan ke dalam halaman cetak, tambahkan atribut `data-printedjs-ignore="true"`:

```html
<nav id="floating-menu" data-printedjs-ignore="true">
	<button onclick="window.print()">Cetak Dokumen</button>
</nav>
```

Elemen dengan atribut `data-printedjs-ignore="true"` atau `data-pagedjs-ignore="true"` akan tetap berada di DOM utama dan tidak akan dipotong atau dihapus saat proses pembuatan halaman.

## Perbandingan Ukuran Bundle

Ukuran `@printedjs/minimal` lebih kecil **60.3%** dibandingkan `paged.polyfill.min.js`:

| Distribusi            | Minified     | Gzip        | Brotli      | Efisiensi vs Paged.js |
| :-------------------- | :----------- | :---------- | :---------- | :-------------------- |
| **Legacy Paged.js**   | 504.1 KB     | 99.0 KB     | 83.6 KB     | Baseline              |
| **Printedjs Minimal** | **200.1 KB** | **52.2 KB** | **44.9 KB** | **-60.3%**            |
