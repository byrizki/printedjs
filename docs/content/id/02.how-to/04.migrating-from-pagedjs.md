Panduan ini menjelaskan perbedaan arsitektur antara Paged.js monolitik dan Printedjs, serta memberikan instruksi langkah demi langkah untuk memigrasikan template, aplikasi, dan custom handler yang sudah ada.

## 1. Perbandingan Arsitektur

| Fitur                  | Legacy Paged.js                                 | Printedjs                                                                               |
| :--------------------- | :---------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **Arsitektur**         | Script monolitik dengan side effect global      | Monorepo modular multi-package (`@printedjs/*`)                                         |
| **Core Runtime**       | Terikat erat ke DOM dan CSSOM browser           | Core terpisah (`@printedjs/core`) dengan kontrak murni; layout via `@printedjs/browser` |
| **Isolasi Surface**    | Memodifikasi elemen halaman dan variabel global | Isolasi surface via mode `root` atau `iframe`                                           |
| **Teardown Lifecycle** | Pembersihan tidak tuntas; style dan DOM bocor   | `renderer.destroy()` deterministik tanpa residu DOM                                     |
| **API Plugin**         | Subclass `Handler` global dengan hook longgar   | `PrintedjsPlugin` bertipe ketat dengan urutan topologis                                 |
| **Ketahanan Loop**     | Rentan infinite loop dan browser tab freeze     | `LayoutProgressGuard` mencegah hang dengan error bertipe                                |
| **Layout Tabel**       | Header sering tidak berulang saat tabel split   | Pengulangan `thead`/`tfoot`, `rowspan` lanjutan, sinkronisasi kolom                     |
| **Lintas Browser**     | Fokus pada Chromium lama                        | 100% terverifikasi di Chromium, Firefox, dan WebKit                                     |
| **TypeScript**         | Tidak ada / Deklarasi ambient seadanya          | 100% strict TypeScript dengan export contract lengkap                                   |
| **Pilihan Bundle**     | Hanya satu script besar                         | Package modular, bundle minimal (`printedjs.min.js`), CLI                               |

## 2. Migrasi Langsung (Script Tag)

Untuk halaman web yang saat ini memuat Paged.js via tag `<script>`:

### Legacy Paged.js

```html
<script src="https://unpkg.com/pagedjs/dist/paged.polyfill.js"></script>
```

### Printedjs Minimal Drop-in

```html
<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>
```

Bundle minimal otomatis mendeteksi stylesheet bertanda `@page`, membagi dokumen saat `DOMContentLoaded`, dan menyediakan object kompatibilitas `window.Paged` untuk script lama Anda.

## 3. Migrasi API Programatik

### Legacy Paged.js

```javascript
import { Previewer } from "pagedjs";

const paged = new Previewer();
await paged.preview(htmlContent, ["print.css"], document.querySelector("#book"));
```

### Printedjs

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

const renderer = createRenderer({
	target: document.querySelector("#book")!,
	isolation: "root", // Atau "iframe" untuk isolasi sandboxed
	plugins: standardPreset(),
});

const result = await renderer.render({
	content: {
		html: htmlContent,
		stylesheets: ["print.css"],
	},
});

console.log(
	`Render selesai: ${result.pages.length} halaman dalam ${result.metrics.durationMs}ms.`,
);
```

## 4. Migrasi Handler ke Plugin

### Legacy Paged.js Handler

Paged.js lama menggunakan pewarisan class global:

```javascript
import { Handler, registerHandlers } from "pagedjs";

class WatermarkHandler extends Handler {
	afterRendered(pages) {
		pages.forEach((page) => {
			const box = page.element.querySelector(".pagedjs_pagebox");
			const mark = document.createElement("div");
			mark.className = "watermark";
			mark.textContent = "RAHASIA";
			box.appendChild(mark);
		});
	}
}
registerHandlers(WatermarkHandler);
```

### Printedjs Plugin

Di Printedjs, plugin berupa pure function yang mengembalikan objek `PrintedjsPlugin` bertipe ketat:

```typescript
import type { PrintedjsPlugin, PluginContext } from "@printedjs/core";

export function watermarkPlugin(text: string): PrintedjsPlugin {
	return {
		name: "watermark",
		afterRender(context: PluginContext) {
			const doc = context.metadata["document"] as Document | undefined;
			if (!doc) return;

			const pages = doc.querySelectorAll<HTMLElement>(".printedjs_page");
			pages.forEach((page) => {
				const box = page.querySelector(".printedjs_pagebox") ?? page;
				const mark = doc.createElement("div");
				mark.className = "watermark";
				mark.textContent = text;
				box.appendChild(mark);
			});
		},
	};
}
```

Daftarkan plugin saat membuat instance renderer:

```typescript
const renderer = createRenderer({
	target: container,
	plugins: [...standardPreset(), watermarkPlugin("RAHASIA")],
});
```

## 5. Selektor CSS & Mode Kompatibilitas

Printedjs menggunakan class CSS `.printedjs_*` dan variabel `--printedjs-*`:

| Legacy Paged.js            | Modern Printedjs             | Catatan                            |
| :------------------------- | :--------------------------- | :--------------------------------- |
| `.pagedjs_pages`           | `.printedjs_pages`           | Container utama seluruh halaman    |
| `.pagedjs_page`            | `.printedjs_page`            | Pembungkus luar satu halaman fisik |
| `.pagedjs_sheet`           | `.printedjs_sheet`           | Area lembar kertas termasuk margin |
| `.pagedjs_pagebox`         | `.printedjs_pagebox`         | Area konten cetak                  |
| `.pagedjs_margin-top-left` | `.printedjs_margin-top-left` | Container margin box tertentu      |
| `.pagedjs_margin-content`  | `.printedjs_margin-content`  | Pembungkus konten di margin box    |

### Mode Kompatibilitas Mundur (Backward Compatibility)

Jika CSS lama Anda masih bergantung pada selektor `.pagedjs_*` atau properti `--pagedjs-*`, aktifkan opsi `pagedjsCompatible: true`:

```typescript
const renderer = createRenderer({
	target: container,
	pagedjsCompatible: true,
	plugins: standardPreset(),
});
```

Saat aktif, Printedjs akan:

- Menghasilkan class ganda pada semua shell halaman (contoh: `class="printedjs_page pagedjs_page"`)
- Menduplikasi CSS custom properties (contoh: `--printedjs-width` dan `--pagedjs-width`)
- Memetakan class margin box dan atribut data versi legacy
