This demo shows `@printedjs/minimal` rendering a complex multi-page document in real time:

- **16 CSS Margin Boxes**: Running headers, section titles via `string-set()`, and page counters (`counter(page) of counter(pages)`).
- **Dynamic Table of Contents**: Dot leaders and dynamic page references via `target-counter()`.
- **Multi-Page Tables**: Automatic `<thead>` repetition, `rowspan` slicing, and subtotal calculation across page boundaries.
- **Footnotes & Callouts**: Floating footnotes positioned at the bottom of the page box.
