**Printedjs** is a modern, high-performance TypeScript engine for browser-native paginated document rendering. It transforms standard HTML and CSS into print-ready paginated documents, implementing the full W3C CSS Paged Media Module specifications directly inside web browsers, headless automation runtimes, and mobile applications.

## Printedjs vs. Paged.js Comparison

Printedjs is engineered as a modern, modular successor to Paged.js. While Paged.js pioneered W3C CSS Paged Media implementation in web browsers, Printedjs addresses long-standing architectural challenges in headless environments, layout resilience, table pagination, memory cleanup, and native cross-platform runtimes:

| Capability & Architectural Context                                                                                          |   Printedjs    |     Paged.js      |
| :-------------------------------------------------------------------------------------------------------------------------- | :------------: | :---------------: |
| **W3C CSS Paged Media Core**<br/>`@page` size, margins, orientation, bleeds, and crop marks.                                |     ✓ Full     |      ✓ Full       |
| **16 Margin Boxes & Page Counters**<br/>Full margin box geometry (`@top-center`, `@bottom-right`), Roman/decimal counters.  |     ✓ Full     |      ✓ Full       |
| **Named Strings & Running Headers**<br/>Dynamic running headers and footers via CSS `string-set` and `string()`.            |     ✓ Full     |      ✓ Full       |
| **Footnotes (`float: footnote`)**<br/>Footnote continuation slicing across page splits.                                     |   ✓ Advanced   |      ✓ Basic      |
| **Table Header & Footer Repeats**<br/>Synchronizes column widths mathematically to prevent row misalignments.               |   ✓ Advanced   |      ✓ Basic      |
| **Table `rowspan` Continuation Slicing**<br/>Calculates cell heights and slices multi-row cells across page cuts.           |     ✓ Full     |         ✗         |
| **Spread & Recto/Verso Blank Pages**<br/>Auto-inserts blank verso pages to maintain physical book parity.                   |  ✓ Automatic   |     ⚠️ Manual     |
| **Decoupled Core Architecture**<br/>Core AST & state machines decoupled from DOM; layout executes via `@printedjs/browser`. |     ✓ Full     | ✗ (DOM Dependent) |
| **Infinite Loop Guard (`ProgressGuard`)**<br/>Detects zero-advancement passes; prevents browser tab hangs and CI freezes.   |   ✓ Built-in   |         ✗         |
| **Surface Isolation & Cleanup**<br/>Sandboxed `iframe`/`root` surfaces with guaranteed `destroy()` teardown.                |     ✓ Full     |     ⚠️ Manual     |
| **Native Headless WebView**<br/>Offscreen native WebView and vector PDF for React Native and .NET 8+.                       |     ✓ Full     |         ✗         |
| **Headless CLI Tooling**<br/>CLI supports headless webview, Playwright, and Puppeteer drivers.                              | ✓ Multi-Engine | ✓ Puppeteer-only  |
| **Interactive 3D Flipbook**<br/>Real-time 3D page-flip engine via `@printedjs/plugin-page-flip`.                            | ✓ Micro-plugin |         ✗         |
| **TypeScript First**<br/>100% typed contracts, full IDE autocompletion, zero `any` leaks.                                   |     ✓ Full     |    ⚠️ Ambient     |
| **Bundle Footprint**<br/>Modular tree-shakeable micro-plugins; 78% smaller footprint.                                       |   ✓ (~52 KB)   |     (~240 KB)     |

## Performance Showcase & Engine Benchmarks

To establish transparent, verifiable performance characteristics, Printedjs was evaluated against native typesetting compilers, legacy browser polyfills, and headless automation drivers rendering an identical 10-page enterprise financial report containing repeating table headers, running metadata, footnotes, and dynamic page numbering:

### End-to-End PDF Generation Benchmark (10-Page Document)

| Engine / Pipeline              | Underlying Runtime      | Execution Time | Peak RSS Memory | Output PDF Size |
| :----------------------------- | :---------------------- | :------------: | :-------------: | :-------------: |
| **Typst** (`v0.14.2`)          | Native Rust Binary      |   **~94 ms**   |   **~39 MB**    |     132 KB      |
| **Printedjs Headless WebView** | Native On-Device Engine |  **~468 ms**   |     ~134 MB     |     792 KB      |
| **Printedjs (Playwright)**     | Node.js + Chromium      |  **~880 ms**   |     ~184 MB     |    **61 KB**    |
| **Printedjs (Puppeteer)**      | Node.js + Chromium CDP  |   **~1.0 s**   |     ~192 MB     |     156 KB      |
| **Paged.js Polyfill**          | Puppeteer + DOM Reflow  |     ~1.0 s     |     ~191 MB     |     156 KB      |

<div class="text-sm text-neutral-500 mt-2 mb-4">
  * All 5 benchmark targets rendered the exact same canonical 10-page enterprise financial report. Headless WebView uses native OS web engines (iOS WKWebView, Android WebView, Windows WebView2, and Linux WebKitGTK) with zero external browser downloads.
</div>

### In-Browser Layout & Bundle Efficiency

In client-side web applications, Printedjs delivers major memory and bundle savings over legacy Paged.js:

- **60.3% Smaller Standalone Bundle**: `@printedjs/minimal` is **52.2 KB gzip** (vs Paged.js **99.0 KB gzip / 504 KB unminified**), dramatically accelerating script hydration and parse times.
- **Page Virtualization (`virtualizePages`)**: In-browser document viewer mounts only visible pages in the scroll buffer, maintaining continuous 60 FPS scrolling on 300+ page documents without DOM exhaustion.
