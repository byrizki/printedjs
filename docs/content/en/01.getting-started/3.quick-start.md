Get up and running with Printedjs in less than five minutes. This guide covers programmatic browser rendering, static HTML drop-in pagination, and headless CLI rendering.

## 1. Programmatic Browser Rendering

Use `@printedjs/browser` and `@printedjs/plugins` to render paginated documents directly inside your web application:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

// 1. Identify a container element in your DOM
const target = document.querySelector("#preview-container")!;

// 2. Instantiate the renderer with surface isolation and plugins
const renderer = createRenderer({
	target,
	isolation: "root", // or "iframe" for sandboxed CSS & script execution
	plugins: standardPreset(),
});

// 3. Render HTML content with CSS Paged Media rules
const result = await renderer.render({
	content: {
		html: `
      <style>
        @page {
          size: A4;
          margin: 25mm 20mm;

          @top-left {
            content: "Printedjs Quick Start Guide";
            font-family: sans-serif;
            font-size: 9pt;
            color: #64748b;
          }

          @bottom-right {
            content: "Page " counter(page) " of " counter(pages);
            font-family: sans-serif;
            font-size: 9pt;
            font-weight: 500;
          }
        }

        h1 {
          color: #0f172a;
          border-bottom: 2px solid #0284c7;
          padding-bottom: 8px;
        }

        p {
          line-height: 1.6;
          color: #334155;
        }
      </style>

      <h1>Hello, Printedjs!</h1>
      <p>This document is automatically split across physical pages with standardized margins, running headers, and dynamic page counters.</p>
    `,
	},
});

console.log(`Rendered ${result.pages.length} pages in ${result.metrics.durationMs}ms`);

// 4. Clean up completely with zero DOM residue when done
// renderer.destroy();
```

## 2. Drop-in Static HTML (Zero Configuration)

If you have an existing static HTML document or want a drop-in replacement for `paged.polyfill.js`:

```html
<!doctype html>
<html lang="en">
	<head>
		<meta charset="UTF-8" />
		<title>My Printable Document</title>
		<!-- 1. Load the standalone Printedjs minimal bundle -->
		<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>

		<style>
			@page {
				size: letter;
				margin: 1in;

				@bottom-center {
					content: "Page " counter(page);
					font-family: sans-serif;
					font-size: 10pt;
				}
			}

			.chapter {
				break-before: page;
			}
		</style>
	</head>
	<body>
		<h1>Chapter 1: The Beginning</h1>
		<p>Content flows cleanly into formatted sheets on DOMContentLoaded.</p>

		<div class="chapter">
			<h1>Chapter 2: Spanning Content</h1>
			<p>Starting on a fresh page with automatic break handling.</p>
		</div>

		<script>
			// Listen for the pagination completion event
			window.addEventListener("printedjs:rendered", (e) => {
				console.log("Document rendering completed!", e.detail);
			});
		</script>
	</body>
</html>
```

## 3. Headless PDF Rendering via CLI

To compile an HTML document into a vector-accurate PDF directly from your command line:

```bash
# Render document.html into document.pdf using the default native engine
pnpm printedjs render document.html -o document.pdf --format A4 --bleed 3mm

# Enable watch mode for live recompilation during authoring
pnpm printedjs render document.html -o document.pdf --watch
```

## 4. In-Browser PDF Export & Print

Printedjs provides built-in utilities to trigger browser print dialogs cleanly without displaying browser UI chrome:

```typescript
import { printDocument } from "@printedjs/browser";

// Trigger print dialog with clean page title and zero screen artifacts
await printDocument({
	target: window,
	pageTitle: "Quarterly Financial Report",
	cleanChrome: true,
});
```
