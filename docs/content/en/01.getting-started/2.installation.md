Printedjs provides multiple installation options depending on your architectural requirements. You can install modular TypeScript packages for application bundlers, load a standalone drop-in script, or install native tooling for CLI and mobile environments.

## Modular Web Packages (Bundlers)

For modern web applications using Vite, Next.js, Nuxt, Webpack, or Rollup, install the browser renderer and plugin preset:

```bash [pnpm]
pnpm add @printedjs/browser @printedjs/plugins
```

```bash [npm]
npm install @printedjs/browser @printedjs/plugins
```

```bash [yarn]
yarn add @printedjs/browser @printedjs/plugins
```

### Optional Packages

```bash
# Decoupled core engine contracts, state machines, and CSS AST tools
pnpm add @printedjs/core

# Non-layout visual inspector overlay and lifecycle trace collector
pnpm add -D @printedjs/devtools

# Legacy browser polyfill compatibility layer
pnpm add @printedjs/polyfill
```

## Standalone Minimal Bundle (CDN / Script Tag)

If you need a zero-configuration drop-in solution without a build step (similar to legacy Paged.js polyfill), use `@printedjs/minimal`:

```html
<!-- Load modern Printedjs standalone runtime -->
<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>
```

The minimal bundle automatically detects `@page` stylesheets, paginates the document body upon `DOMContentLoaded`, and exposes standard `window.Paged` compatibility APIs for existing scripts.

## Headless PDF Generation CLI

To compile HTML and CSS Paged Media files directly to vector PDFs from your terminal, CI/CD pipeline, or backend service:

```bash [pnpm]
pnpm add -D @printedjs/cli
```

```bash [npm]
npm install -D @printedjs/cli
```

Or run directly with `npx` / `pnpm dlx`:

```bash
pnpm dlx @printedjs/cli render document.html -o output.pdf
```

The CLI defaults to the bundled native `webview` engine (zero extra downloads). If you prefer browser automation drivers, optionally install Playwright or Puppeteer:

```bash
# Playwright driver
pnpm add -D playwright
pnpm dlx playwright install chromium

# Puppeteer driver
pnpm add -D puppeteer
```

## Native Headless Webview

### React Native (iOS & Android)

For React Native applications generating PDFs in background webviews:

```bash
pnpm add @printedjs/headless-webview
```

For iOS, ensure pods are installed:

```bash
cd ios && pod install
```

### .NET 8 / MAUI / Unity (NuGet)

For C# and .NET enterprise systems:

```bash [.NET CLI]
dotnet add package PrintedJs.HeadlessWebView
```

```xml [Package Manager]
<PackageReference Include="PrintedJs.HeadlessWebView" Version="0.2.2" />
```

## Verification

Verify your installation by running the CLI or importing the renderer in your project:

```bash
pnpm printedjs --version
```
