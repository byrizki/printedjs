This roadmap outlines the architectural evolution, completed engineering milestones, and forward-looking horizons for **Printedjs**.

## Strategic Engineering Tracks

### Track 1: Core Architecture & Resiliency

Establishes a rock-solid, decoupled core layout foundation that eliminates browser lockups and memory leaks.

| Milestone                    | Package Scope        | Key Deliverables                                                                                         | Status      |
| :--------------------------- | :------------------- | :------------------------------------------------------------------------------------------------------- | :---------- |
| **Pure Core Contracts**      | `@printedjs/core`    | Decoupled core pagination contracts, CSS AST facade, topological plugin pipeline.                        | `Delivered` |
| **Surface Isolation**        | `@printedjs/browser` | Clean separation between host DOM and rendered document via `root` and sandboxed `iframe`.               | `Delivered` |
| **Infinite Loop Protection** | `@printedjs/browser` | `LayoutProgressGuard` state machine detecting zero-advance break tokens and unbreakable block overflows. | `Delivered` |
| **Clean Blank Page Parity**  | `@printedjs/browser` | Automatic physical blank page generation for `break-before: recto/verso` and book signatures.            | `Delivered` |

### Track 2: CSS Paged Media Standards Conformance

Full compliance with W3C CSS Paged Media specifications for enterprise-grade publishing.

| Milestone                     | Package Scope                           | Key Deliverables                                                                                            | Status      |
| :---------------------------- | :-------------------------------------- | :---------------------------------------------------------------------------------------------------------- | :---------- |
| **16 CSS Margin Boxes**       | `@printedjs/plugins`                    | Full perimeter margin boxes, running headers, footers, and corner boxes.                                    | `Delivered` |
| **Dynamic String Sets**       | `@printedjs/plugins`                    | `string-set` and `content: string(...)` for dynamic chapter/section titles across pages.                    | `Delivered` |
| **Multi-System Counters**     | `@printedjs/core`, `@printedjs/plugins` | Pure core `counter()` formatting (`lower-roman`, `upper-alpha`, `decimal-leading-zero`) and TOC resolution. | `Delivered` |
| **Multi-Page Tables**         | `@printedjs/plugins`                    | Automatic `<thead>` and `<tfoot>` repetition, cell rowspan slicing, and subtotal calculation.               | `Delivered` |
| **Mirrored Margins & Gutter** | `@printedjs/plugins`                    | `margin-inside`, `margin-outside`, and binding gutter math for recto/verso page geometry.                   | `Delivered` |

### Track 3: Platform, CLI & Native Runtimes

Extends document pagination beyond standard browsers into headless automation and native mobile/desktop runtimes.

| Milestone                           | Package Scope                 | Key Deliverables                                                                          | Status      |
| :---------------------------------- | :---------------------------- | :---------------------------------------------------------------------------------------- | :---------- |
| **Headless PDF CLI**                | `@printedjs/cli`              | Production CLI with auto-detecting Playwright and Puppeteer headless browser drivers.     | `Delivered` |
| **Cross-Platform Headless WebView** | `@printedjs/headless-webview` | Native WebKit/Wry driver for React Native iOS/Android and .NET cross-platform runtimes.   | `Delivered` |
| **Visual Parity Matrix**            | Test Suite                    | 90-case visual regression suite automated across Chromium, Firefox, and WebKit on CI.     | `Delivered` |
| **Zero-Config Minimal Bundle**      | `@printedjs/minimal`          | 52 KB gzipped all-in-one distribution bundle with automatic `@page` stylesheet discovery. | `Delivered` |

### Track 4: Reader Ecosystem & Developer Experience

Tools and presentation layers for previewing, inspecting, and reading paginated documents.

| Milestone                   | Package Scope                 | Key Deliverables                                                                            | Status      |
| :-------------------------- | :---------------------------- | :------------------------------------------------------------------------------------------ | :---------- |
| **DevTools Overlay**        | `@printedjs/devtools`         | Non-layout visual overlay showing page box dimensions, bleed boundaries, and render traces. | `Delivered` |
| **Spread & Reader Modes**   | `@printedjs/plugins`          | Two-page spread reading mode with simulated physical spine fold shadow.                     | `Delivered` |
| **3D Interactive Flipbook** | `@printedjs/plugin-page-flip` | Physics-based 3D page turning with procedural page-curl sound synthesis.                    | `Delivered` |
| **Interactive TOC Drawer**  | `@printedjs/plugins`          | Dynamic navigation drawer linking directly to paginated headings and document anchors.      | `Delivered` |

## Future Horizons

### 1. Off-Thread Streaming Pagination

- Offload CSS AST parsing and text geometry measurement to Web Workers.
- Stream generated pages progressively over WebSockets or Chunked HTTP for high-throughput enterprise batch rendering.

### 2. Accessible PDF/A & Tagged Document Output

- Direct emission of PDF/A-compliant metadata, tagged PDF accessibility trees (WCAG 2.1), and interactive hyperlinked tables of contents during headless CLI rendering.

### 3. GPU-Accelerated Canvas Document Viewer

- Render pre-calculated page layouts via HTML5 Canvas or WebGPU for 60fps pan/zoom in high-density catalog and reader applications.
