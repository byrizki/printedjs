The `@printedjs/browser` package provides the main DOM-level rendering engine, range measurement adapters, surface containment abstractions, and deterministic teardown lifecycles.

## Creating a Renderer

Initialize a renderer using the `createRenderer` factory function:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

const targetContainer = document.querySelector("#preview")!;

const renderer = createRenderer({
	target: targetContainer,
	isolation: "root", // "root" | "iframe"
	pagedjsCompatible: false, // Set to true to emit legacy .pagedjs_* classes
	plugins: standardPreset(),
});
```

### Configuration Options

| Option              | Type                 | Default      | Description                                                                      |
| :------------------ | :------------------- | :----------- | :------------------------------------------------------------------------------- |
| `target`            | `HTMLElement`        | **Required** | The DOM element where the rendered pages will be mounted.                        |
| `isolation`         | `"root" \| "iframe"` | `"root"`     | Surface isolation mode (container-based vs sandboxed iframe).                    |
| `plugins`           | `PrintedjsPlugin[]`  | `[]`         | List of plugins to execute across lifecycle hooks.                               |
| `pagedjsCompatible` | `boolean`            | `false`      | When true, emits dual `.printedjs_*` and `.pagedjs_*` CSS classes and variables. |
| `baseUrl`           | `string`             | `undefined`  | Base URL used to resolve relative asset paths and `@import` rules.               |

## Surface Isolation Modes

Printedjs provides two distinct surface isolation modes:

| Capability        | Root Surface (`isolation: "root"`)                        | Iframe Surface (`isolation: "iframe"`)           |
| :---------------- | :-------------------------------------------------------- | :----------------------------------------------- |
| **DOM Target**    | Direct DOM container element                              | Sandboxed same-origin `<iframe>`                 |
| **Throughput**    | Highest rendering throughput (no iframe overhead)         | Sandboxed context with isolated layout           |
| **CSS Boundary**  | Scoped by `.printedjs_pages` wrapper                      | Complete CSS & script boundary                   |
| **Best Used For** | Single-page apps, interactive editors & trusted templates | Untrusted user HTML, apps with global CSS resets |

### 1. Root Surface (`isolation: "root"`)

Directly appends the page shell containers inside the target element. Recommended for single-page applications, interactive document editors, and trusted templates where maximum rendering performance is desired.

### 2. Iframe Surface (`isolation: "iframe"`)

Spawns a sandboxed `<iframe>` inside the target element and renders the pages within the frame's isolated browsing context. This guarantees that host styles (e.g. Tailwind or Bootstrap resets) cannot inadvertently bleed into print typography, and template styles cannot escape into the host app.

## Executing a Render

Invoke `renderer.render()` with content and optional stylesheets:

```typescript
const result = await renderer.render({
	content: {
		html: "<article><h1>Annual Statement</h1><p>...</p></article>",
		stylesheets: ["/css/print-theme.css"],
	},
	baseUrl: "https://example.com/assets/",
});

console.log(`Rendered ${result.pages.length} pages in ${result.metrics.durationMs}ms`);
```

### Render Result Structure

The returned `RenderResult` contains detailed layout metrics and page references:

```typescript
interface RenderResult {
	pages: PageResult[];
	metrics: {
		durationMs: number;
		parseDurationMs: number;
		layoutDurationMs: number;
		pageCount: number;
	};
}
```

## Deterministic Teardown (`renderer.destroy()`)

A critical advantage of Printedjs over legacy tools is clean lifecycle teardown. Calling `destroy()` restores the host DOM completely:

```typescript
// Completely remove mounted surfaces, observers, event listeners, and injected styles:
renderer.destroy();
```

No orphan DOM nodes, no dangling style sheets, and zero memory leaks.

## Direct PDF Print Trigger

Use `printDocument` to open the browser print dialog with automatic cleanup of screen toolbars and UI artifacts:

```typescript
import { printDocument } from "@printedjs/browser";

await printDocument({
	target: renderer.surface.window ?? window,
	pageTitle: "Official Certificate",
	cleanChrome: true,
});
```
