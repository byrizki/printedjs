`@printedjs/minimal` is an all-in-one pre-bundled distribution of Printedjs. It bundles the core engine, browser layout adapter, standard plugin preset, and polyfills into a single lightweight script (`printedjs.min.js`, ~200 KB minified / ~52 KB gzip).

It is designed for static websites, documentation generators, report servers, and drop-in replacements for legacy `paged.polyfill.js`.

## Basic Usage

Include the script in your HTML `<head>` or at the end of `<body>`:

```html
<!doctype html>
<html lang="en">
	<head>
		<meta charset="UTF-8" />
		<title>Enterprise Specification</title>
		<!-- Include Printedjs Minimal -->
		<script src="https://cdn.jsdelivr.net/npm/@printedjs/minimal/dist/index.min.global.js"></script>

		<style>
			@page {
				size: A4;
				margin: 20mm;

				@bottom-right {
					content: "Page " counter(page) " of " counter(pages);
					font-family: sans-serif;
					font-size: 8.5pt;
				}
			}

			h1 {
				break-after: avoid;
			}

			.section-break {
				break-before: page;
			}
		</style>
	</head>
	<body>
		<h1>Report Overview</h1>
		<p>Content paginates automatically when the page loads.</p>

		<div class="section-break">
			<h2>Financial Summary</h2>
			<p>This content begins on a fresh page.</p>
		</div>
	</body>
</html>
```

## Automatic Initialization

When `@printedjs/minimal` loads:

1. It observes document readiness. If the document is still loading, it attaches a listener to `DOMContentLoaded`.
2. It parses all inline `<style>` blocks and external `<link rel="stylesheet">` files for CSS `@page` at-rules.
3. If `@page` rules or paged media selectors are detected, it automatically kicks off the pagination pipeline.
4. It replaces the unpaginated DOM with standardized `.printedjs_page` shells.

## Lifecycle Events

Printedjs emits standard DOM custom events so you can coordinate animations, loading overlays, or automated test runners:

```javascript
// Triggered once pagination finishes and pages are mounted
window.addEventListener(
	"printedjs:rendered",
	(event) => {
		console.log("Rendering complete!");
		console.log("Pages generated:", event.detail.pages.length);
		console.log("Duration:", event.detail.metrics.durationMs);

		// Example: dismiss loading overlay
		document.getElementById("loader")?.remove();
	},
	{ once: true },
);

// Also dispatches legacy pagedjs:rendered for backward compatibility:
window.addEventListener("pagedjs:rendered", () => {
	console.log("Legacy compatibility event fired");
});
```

## Preventing Elements from Being Paginated

To prevent specific elements (such as fixed navigation pills, floating toolbars, or debug monitors) from being absorbed into paginated page shells, add `data-printedjs-ignore="true"`:

```html
<nav id="floating-menu" data-printedjs-ignore="true">
	<a href="/dashboard">Return to Dashboard</a>
</nav>
```

Elements with `data-printedjs-ignore="true"` or `data-pagedjs-ignore="true"` remain anchored in the root DOM and will not be paginated or cleared during page construction.
