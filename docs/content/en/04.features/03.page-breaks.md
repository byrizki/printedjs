Printedjs provides comprehensive support for modern CSS Fragmentation break properties as well as legacy `page-break-*` aliases.

## Break Properties Overview

| Modern CSS Property | Legacy Equivalent   | Supported Values                                                     |
| :------------------ | :------------------ | :------------------------------------------------------------------- |
| `break-before`      | `page-break-before` | `auto`, `always`, `page`, `left`, `right`, `recto`, `verso`, `avoid` |
| `break-after`       | `page-break-after`  | `auto`, `always`, `page`, `left`, `right`, `recto`, `verso`, `avoid` |
| `break-inside`      | `page-break-inside` | `auto`, `avoid`, `avoid-page`                                        |

---

## Preventing Breaks Inside Blocks

Ensure cards, signature lines, or tables remain intact on a single sheet using `break-inside: avoid`:

```css
/* Prevent breaking across pages */
.signature-block,
.kpi-card,
figure {
	break-inside: avoid;
}

/* Prevent headings from being orphaned at the bottom of a page */
h1,
h2,
h3 {
	break-after: avoid;
}
```

## Facing Spreads & Physical Blank Pages

When producing physical books or duplex-printed manuals, chapters typically must start on a **right-hand (recto / odd)** page.

If the previous chapter ends on a right-hand page (Page 5), simply advancing to the next sheet would place the new chapter on the left-hand page (Page 6).

Printedjs calculates physical sheet parity and automatically inserts a **blank page** (Page 6) so that the chapter begins on the right page (Page 7):

```css
.major-chapter {
	/* Forces chapter to open on a right-hand (odd) page */
	break-before: right; /* or 'recto' */
}

/* Style the inserted blank page using the :blank pseudo-class */
@page :blank {
	@top-left {
		content: none;
	}
	@bottom-right {
		content: none;
	}
}
```

::

### Supported Spread Break Values

- `break-before: left` / `verso` — Forces content onto a left-hand (even) page.
- `break-before: right` / `recto` — Forces content onto a right-hand (odd) page.
- `break-after: left` / `right` — Enforces trailing parity after a document division.

## Widow & Orphan Controls

Prevent isolated dangling lines at page boundaries:

```css
p {
	orphans: 2; /* Minimum lines required at bottom of previous page */
	widows: 2; /* Minimum lines required at top of next page */
}
```
