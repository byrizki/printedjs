Printedjs provides comprehensive support for CSS Paged Media page counters, Roman/alphabetic numbering formats, section resets, and dynamic Table of Contents (TOC) with leader dots.

## 1. Page Counters & Numbering Styles

CSS Paged Media defines two primary counters:

- `counter(page)`: The current sheet number.
- `counter(pages)`: The total page count of the rendered document.

```css
@page {
	@bottom-right {
		content: "Page " counter(page) " of " counter(pages);
		font-size: 8.5pt;
		color: #64748b;
	}
}

/* Lowercase Roman numerals (i, ii, iii...) for frontmatter */
@page frontmatter {
	@bottom-right {
		content: "Page " counter(page, lower-roman);
	}
}
```

### Supported Counter Styles

| Counter Style Keyword  | Example Sequence     | Common Use Case                              |
| :--------------------- | :------------------- | :------------------------------------------- |
| `decimal` (default)    | 1, 2, 3, 4, 5...     | Standard document body                       |
| `decimal-leading-zero` | 01, 02, 03, 04...    | Formal architectural catalogs                |
| `lower-roman`          | i, ii, iii, iv, v... | Table of contents, preface, frontmatter      |
| `upper-roman`          | I, II, III, IV, V... | Major parts, appendices, executive summaries |
| `lower-alpha`          | a, b, c, d, e...     | Footnote callouts, sub-sections              |
| `upper-alpha`          | A, B, C, D, E...     | Exhibits, schedules, attachments             |

---

## 2. Section Resetting (`counter-reset`)

To restart page numbering at 1 when transitioning from introductory frontmatter to the main document body:

```css
.main-content {
	break-before: page;
	counter-reset: page 1;
}
```

---

## 3. Dynamic Table of Contents (`target-counter`)

Printedjs supports W3C `target-counter()`. It automatically inspects destination anchor IDs and injects their resolved physical page number into the Table of Contents:

```html
<nav class="toc-container">
	<div class="toc-title">Table of Contents</div>
	<ul class="toc-list">
		<li class="toc-item">
			<a href="#sec-executive">
				<span class="toc-label">1. Executive Summary</span>
				<span class="toc-dots"></span>
				<span class="toc-target"></span>
			</a>
		</li>
		<li class="toc-item">
			<a href="#sec-architecture">
				<span class="toc-label">2. Architectural Tenets</span>
				<span class="toc-dots"></span>
				<span class="toc-target"></span>
			</a>
		</li>
	</ul>
</nav>
```

```css
.toc-dots {
	flex-grow: 1;
	border-bottom: 1px dotted #94a3b8;
	margin: 0 6px;
}

.toc-item a .toc-target::after {
	content: target-counter(attr(href), page);
	font-weight: 700;
	color: #0284c7;
}
```
