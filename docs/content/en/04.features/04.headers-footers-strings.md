In multi-page documents, running headers and footers display the active chapter title, section heading, or document metadata at the top or bottom of every page.

Printedjs provides two complementary mechanisms to achieve this:

1. **Named Strings (`string-set` & `string()`):** Extracts plain text from document headings and stamps it into `@top-left`, `@top-right`, etc.
2. **Running Elements (`position: running()` & `element()`):** Moves complex HTML elements (including logos, styled badges, or multi-line layouts) directly into margin boxes.

---

## 1. Named Strings (`string-set`)

The `string-set` property captures text from an element in the body and assigns it to a named variable:

```css
/* 1. Extract heading text whenever an h2 appears */
h2.section-heading {
	string-set: current-section content();
}

/* 2. Display the string in the top-right margin box */
@page {
	size: A4;
	margin: 25mm 20mm;

	@top-right {
		content: string(current-section);
		font-size: 8.5pt;
		font-weight: 500;
		color: #64748b;
	}
}
```

### String Resolution Keywords

When multiple headings appear on a single page, you can control which occurrence is selected using lookup keywords:

```css
@page {
	/* Uses the first heading occurrence on this page (default) */
	@top-right {
		content: string(current-section, first);
	}

	/* Uses the last heading occurrence on this page */
	@top-right {
		content: string(current-section, last);
	}

	/* Uses the value active at the very start of the page */
	@top-right {
		content: string(current-section, start);
	}
}
```

---

## 2. Running Elements (`position: running`)

When headers require complex formatting—such as company logos, SVG icons, tables, or multi-line metadata—use running elements:

```html
<!-- HTML header template placed in your document body -->
<header class="doc-header">
	<div class="header-logo">
		<img src="/logo.svg" alt="Company Logo" width="120" />
	</div>
	<div class="header-meta">
		<span class="confidential-badge">CONFIDENTIAL</span>
		<span class="report-id">Q4-2026-AUDIT</span>
	</div>
</header>

<main>
	<h1>Executive Summary</h1>
	<p>Body content flows across pages...</p>
</main>
```

```css
/* 1. Take the element out of normal flow and assign to a running slot */
.doc-header {
	position: running(pageHeader);
}

/* 2. Stamp the element into the desired margin box */
@page {
	size: A4;
	margin-top: 35mm; /* Allocate space for the header */

	@top-center {
		content: element(pageHeader);
	}
}
```

### Suppressing on Cover Pages

To prevent the running header from displaying on the first page:

```css
@page :first {
	@top-center {
		content: none;
	}
}
```
