The W3C **CSS Paged Media Module** defines how web content is formatted, broken, and styled across discrete physical printed pages or presentation sheets.

Printedjs implements CSS Paged Media specifications directly in modern browsers via standard CSS parsing and DOM Range layout slicing.

::feature-preview{feature="summary"}
::

## The Standard Preset (`standardPreset()`)

All core layout plugins are bundled in `@printedjs/plugins` and can be loaded together via `standardPreset()`:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";

const renderer = createRenderer({
	target: document.querySelector("#preview")!,
	plugins: standardPreset(), // Loads all standard Paged Media plugins
});
```

## Supported Specifications & Plugins

| Specification / Capability  | Plugin Name              | Key CSS Selectors & Declarations                                       |
| :-------------------------- | :----------------------- | :--------------------------------------------------------------------- |
| **Page Geometry & Margins** | `pageRulesPlugin`        | `@page`, `size`, `margin`, `bleed`, `marks: crop cross`                |
| **16 Margin Boxes**         | `generatedContentPlugin` | `@top-left`, `@top-center`, `@bottom-right`, margin tracks             |
| **Break Semantics**         | `breaksPlugin`           | `break-before`, `break-after`, `break-inside: avoid`, `page-break-*`   |
| **Blank Page Parity**       | `breaksPlugin`           | `break-before: left / right / recto / verso`                           |
| **Named Strings**           | `stringsPlugin`          | `string-set: title content()`, `content: string(title)`                |
| **Running Elements**        | `runningHeadersPlugin`   | `position: running(header)`, `content: element(header)`                |
| **Page Counters**           | `countersPlugin`         | `counter(page)`, `counter(pages)`, `target-counter()`, `counter-reset` |
| **Footnotes**               | `footnotesPlugin`        | `float: footnote`, `@footnote`, multi-page footnote slicing            |
| **Multi-Column Layout**     | `columnsPlugin`          | `columns`, `column-count`, `column-gap`, `column-fill: balance`        |
| **Widows & Orphans**        | `widowsOrphansPlugin`    | `widows: 2`, `orphans: 2`                                              |
| **Math Formula Guard**      | `mathPlugin`             | Formula break protection for KaTeX, MathJax, `<math>`                  |
| **Hyphenation**             | `hyphenationPlugin`      | Soft hyphen preservation and hyphenation normalization                 |
| **Document Bookmarks**      | `bookmarksPlugin`        | Hierarchical heading outline extraction for PDF bookmarks              |
| **Presentation Views**      | `pageViewsPlugin`        | Single-page, spread facing-pages, and 3D flipbook presentation         |
