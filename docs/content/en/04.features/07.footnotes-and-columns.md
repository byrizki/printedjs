Printedjs implements complex typographical features defined in W3C Generated Content for Paged Media (GCPM) and CSS Multi-column Layout, including bottom-of-page footnotes and balanced multi-column flows.

## 1. W3C Footnotes (`float: footnote`)

Footnotes allow inline references to be moved automatically to a dedicated footnote area at the bottom of the current sheet.

### HTML Markup & Styling

```html
<p>
	Microservice communication latencies were measured across 10,000 requests
	<span class="footnote"
		>Benchmarks conducted on Kubernetes v1.31 running Linux 6.12 kernels with AMD EPYC
		processors.</span
	>
	under steady peak loads.
</p>
```

```css
span.footnote {
	float: footnote;
	font-size: 8pt;
	color: #64748b;
	line-height: 1.4;
}

@page {
	@footnote {
		border-top: 1px solid #cbd5e1;
		padding-top: 8px;
		margin-top: 14px;
	}
}
```

## 2. Multi-Column Layout (`columns`)

Printedjs supports CSS multi-column flows with automatic height balancing:

```css
.editorial-columns {
	column-count: 2; /* or 'columns: 2;' */
	column-gap: 18mm;
	column-rule: 1px solid #e2e8f0;
	column-fill: balance; /* Automatically balances text column heights */
}

/* Span an element across all columns */
.editorial-columns .full-width-figure {
	column-span: all;
	margin: 16px 0;
	break-inside: avoid;
}
```

## 3. Math Formula Break Protection (`mathPlugin`)

Mathematical notation rendered via KaTeX, MathJax, or MathML often suffers from broken symbols or truncated fractions when split across a page boundary.

The `mathPlugin` in Printedjs automatically wraps math expressions with avoid-break constraints:

```css
.katex-display,
mjx-container[display="true"],
math[display="block"] {
	break-inside: avoid;
}
```
