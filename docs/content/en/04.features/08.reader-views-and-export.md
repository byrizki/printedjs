Beyond static print output, Printedjs provides interactive presentation modes, document navigation drawers, and direct client-side PDF export.

## 1. Interactive 3D Flipbook

The `@printedjs/plugin-page-flip` package delivers a hardware-accelerated 3D turning-page book presentation. It enables drag-and-flip corner curling, keyboard navigation, and realistic paper curl deformation directly inside modern browsers:

```typescript
import { createRenderer } from "@printedjs/browser";
import { standardPreset } from "@printedjs/plugins";
import { pageFlipPlugin } from "@printedjs/plugin-page-flip";

const renderer = createRenderer({
	target: document.querySelector("#reader")!,
	plugins: [
		...standardPreset(),
		pageFlipPlugin({
			width: 300,
			height: 420,
			showCover: true,
		}),
	],
});
```

## 2. Facing Spreads (`"spread"`)

The two-page spread view presents facing pages side-by-side, mirroring physical book layouts with spine gutter binding and fold shadows:

```typescript
import { pageViewsPlugin } from "@printedjs/plugins";

// In your renderer configuration:
pageViewsPlugin({ defaultMode: "spread" });
```

## 3. Interactive TOC Bookmark Drawer

For long documents (manuals, annual reports, specifications), Printedjs provides a collapsible bookmark navigation drawer:

```typescript
import { createBookmarksDrawer } from "@printedjs/plugins";

const drawer = createBookmarksDrawer({
	target: document.body,
	container: document.querySelector("#reader-viewport")!,
	title: "Document Navigation",
	collapsible: true,
});
```

---

## 4. Client-Side PDF Export & Direct Print

Trigger browser print spooling programmatically with zero UI chrome:

```typescript
import { printDocument } from "@printedjs/browser";

// Trigger print dialog with clean page title and zero screen artifacts
await printDocument({
	target: window,
	pageTitle: "Official Enterprise Policy",
	cleanChrome: true, // Hides screen overlays, scrollbars, and tools
});
```
